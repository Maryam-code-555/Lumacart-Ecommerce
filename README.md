# LumaCart E-commerce Website 🛍️

A modern, responsive e-commerce website built with HTML5, CSS3 and Vanilla JavaScript.

## 🚀 Features

- Responsive design
- Mobile navigation
- Product categories
- Product filtering
- Product search
- Shopping cart
- Quantity controls
- Wishlist interaction
- Product quick-view modal
- Product pricing
- Customer reviews
- Newsletter form
- Contact form validation
- Smooth scrolling
- Scroll animations

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## 📱 Responsive Design

The website is optimized for:

- Desktop
- Tablet
- Mobile
